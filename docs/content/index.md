## Valar and Svelte

Valar is the brand for a series of component libraries. Svelte is the current framework implementation. React and Vue versions are not available yet.

This repository holds component source you can edit directly, along with composed blocks, themes, and examples. The base component styles are kept as they are for now; they will be customized against the Valar design spec over time.

## Where to start

- [Browse the components](/docs/components): interactive previews, code, and usage.
- [Install locally](/docs/installation): use the CLI and registry from this repository.
- [Theming](/docs/theming): the current semantic variables and light/dark configuration.
- [License & Credits](/docs/about): third-party licenses and technical provenance.

## Distribution status

This is a local development build. No npm packages have been published and no public registry has been deployed. CLI commands in these docs run from the root of the Valar repository.
