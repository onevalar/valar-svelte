## Valar 与 Svelte

Valar 是组件库系列的品牌，Svelte 是当前的框架实现。React、Vue 版本尚未提供。

这里维护可直接修改的组件源码、组合区块、主题和示例。当前保留基础组件样式，后续按 Valar 的设计规范逐步定制。

## 从哪里开始

- [浏览组件](/docs/components)：交互预览、代码和用法。
- [本地安装](/docs/installation)：使用仓库内的 CLI 和 registry。
- [主题](/docs/theming)：现有语义变量与深浅色配置。
- [许可与来源](/docs/about)：第三方许可和技术来源。

## 分发状态

当前为本地开发版本，尚未发布 npm 包或部署公开 registry。页面中的 CLI 命令在 Valar 仓库根目录执行。
