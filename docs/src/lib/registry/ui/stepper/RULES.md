# Stepper 设计规范

- 用于有先后顺序的多步流程（注册、配置向导）；步骤之间可以随意切换、没有顺序时用 Tabs。
- 步骤通过 `steps` 数组定义，每项有稳定的 `id` 和 `title`；用 `bind:value` 绑定当前步骤，内容在 `children` snippet 中按 `step.id` 渲染。
- 默认按顺序前进（`linear`）；离开当前步骤前的校验写在 `beforeChange`，返回字符串会作为错误显示并阻止切换，不要自己拦截按钮。
- 某一步的错误写在该步的 `error` 字段，禁用的步骤设 `disabled`。
- 默认读屏名称是“步骤进度”，播报与默认错误文案也是中文；其他语言传 `aria-label` 和 `messages`。切换步骤后焦点会移到新内容，不要再手动移动焦点。
